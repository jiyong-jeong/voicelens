# 이슈 · 기술 부채 · 로드맵

상태: 🔴 배포 전 필수 · 🟠 품질 영향 큼 · 🟡 개선

## 보안

| ID | 상태 | 내용 | 조치 |
|---|---|---|---|
| S-1 | 🔴 | Gemini API 키가 채팅/설정 과정에서 평문으로 공유됨 | Google AI Studio에서 **키 재발급(rotate)** 후 `apps/server/.env` 교체. 운영은 Secret Manager 등 사용 |
| S-2 | 🔴 | `APP_TOKEN` 은 앱 번들에 포함되는 공유 문자열 → 누구나 서버를 호출 가능 | 사용자 인증(Firebase Auth/Supabase 등 + JWT 검증), 사용자별 레이트 리밋·쿼터, App Check/Play Integrity |
| S-3 | 🟠 | 서버에 요청 크기(20MB) 외 제한 없음, 비용 폭주 가능 | 레이트 리밋, 이미지 해상도 상한 서버측 재검증, 타임아웃 |
| S-4 | 🟡 | 사용자 사진·음성이 외부 LLM으로 전송됨 | 개인정보 처리방침, 첫 실행 동의 화면, 로그에 base64 남기지 않기(현재 hono logger는 경로만 기록) |

## 기능/기술

| ID | 상태 | 내용 | 방향 |
|---|---|---|---|
| T-1 | 🟠 | 영역이 **바운딩 박스(사각형)** 뿐 — 인물·하늘 같은 불규칙 영역에 보정이 사각형으로 번짐. 디자인의 브러시/지우개 미구현 | Gemini 세그멘테이션 마스크(base64 PNG) 또는 온디바이스 세그멘테이션 → Skia 마스크(`Mask`/알파 이미지)로 합성, 경계 페더링 |
| T-2 | 🟠 | 하이라이트/그림자가 선형 매트릭스 근사 | Skia `RuntimeShader`(SkSL)로 톤 커브 구현. 샤프닝/클래리티도 셰이더로 |
| T-3 | 🟠 | 저장이 **화면 해상도 스냅샷** (`makeImageSnapshot`) | `Skia.Surface.MakeOffscreen(w,h)` 로 원본 해상도 렌더 후 인코딩. 작업 해상도(1536)와 저장 해상도 분리 |
| T-4 | 🟠 | 생성형 편집의 영역 한정이 프롬프트 의존 → 영역 밖도 바뀔 수 있음. 결과 해상도/비율도 달라질 수 있음 | 결과를 원본 크기로 맞춘 뒤 **영역 마스크로만 합성**(디바이스). 비율 불일치 시 경고 |
| T-5 | 🟠 | 음성 지연: 받아쓰기(~3s) + 계획(~5s) 직렬 | ① `/api/voice-command` 를 오디오+이미지 단일 멀티모달 호출로 합치기 ② Live API 스트리밍(`gemini-3.8-live`, `gemini-3.5-transcribe-live`)으로 말하는 중 자막·발화 종료 자동 감지 ③ 계획 응답 스트리밍 |
| T-6 | 🟡 | 탭-토글 녹음만 지원 (자동 종료 없음) | VAD(무음 감지) 자동 종료, 길게 누르기(push-to-talk) 옵션 |
| T-7 | 🟡 | 서버/앱 타입이 복사본 (`schema.ts` ↔ `types.ts`) | `packages/shared` 워크스페이스로 zod 스키마 공유 |
| T-8 | 🟡 | 공급자 선택이 전역 1개 | 역할별 공급자 매핑(예: STT=Gemini, 계획=Claude) — `registry` 를 역할 단위로 분리 |
| T-9 | 🟡 | 대화 맥락 없음 — "좀 더", "아까처럼" 이해 불가 | 최근 명령 이력과 현재 `Adjustments` 를 계획 프롬프트에 포함 |
| T-10 | 🟡 | 계획 결과를 수정할 UI 없음 | 적용 내역 행을 탭 → 슬라이더로 미세조정 |
| T-11 | 🟡 | 영역 감지 결과가 여러 개일 때 첫 번째만 선택 | 결과 목록에서 탭해서 선택/다중 선택 |
| T-12 | 🟡 | 테스트 없음 (스모크만) | `color-matrix` 단위 테스트, 서버 라우트 테스트(프로바이더 목), 프롬프트 회귀 세트(발화 → 기대 계획) |
| T-13 | 🟡 | 에러 UX 최소 (저장 실패 등 일부는 처리 안 된 Promise) | 토스트/재시도, 오프라인 감지 |

## 로드맵 제안

1. **보안 기본** — S-1 키 교체, S-2 인증 + 레이트 리밋
2. **보정 품질** — T-1 마스크, T-3 원본 해상도 저장, T-4 생성형 결과 마스크 합성
3. **음성 경험** — T-5 단일 호출/스트리밍, T-6 VAD, T-9 대화 맥락
4. **다중 LLM** — T-7 공유 스키마, T-8 역할별 공급자, Claude 공급자 추가 후 계획 품질 A/B
5. **완성도** — D-1 폰트, T-10 미세조정 UI, T-12 테스트
